**Find Anything Application**

Project Description:

This application is a collection of calculators built with HTML, CSS, and JavaScript to handle various mathematical and financial computations interactively. Each calculator serves a specific purpose and displays results dynamically with appropriate visual feedback.

<hr/>

Features:

1. BMI Calculator
* Calculates the Body Mass Index (BMI) based on height (in centimeters) and weight (in kilograms).
* Categorizes results into Underweight, Normal, Overweight, or Obese.
* Displays an emoji to represent the BMI category.
2. Loan Calculator
* Calculates the Equated Monthly Installment (EMI) for a loan based on the principal amount, interest rate, and number of months.
* Displays the EMI result and an emoji representing the calculation.
3. Profit & Loss Calculator
* Determines profit or loss by comparing the cost price and selling price.
* Indicates profit or loss amount and displays respective emojis.
4. Simple Interest Calculator
* Calculates the total amount accumulated (principal + interest) over a specified number of years at a given interest rate.
* Provides detailed output with the total investment and generated returns.
5. Percentage Calculator
* Calculates a percentage of a given amount.
* Displays the calculated percentage and associated emoji.
6. Tip Calculator
* Calculates the tip amount and total bill based on the bill amount and tip percentage.
* Provides a breakdown of the tip and total cost.
7. Grade Calculator
* Calculates the sum and average of marks for three subjects (Math, Physics, Chemistry).
* Displays performance emojis based on score ranges.
8. Password Strength Checker
* Dynamically evaluates password strength based on:
* Presence of numbers, lowercase letters, uppercase letters, and special characters.
* Length of the password.
* Visualizes password strength using a progress bar with varying colors and widths.
9. Age Calculator
* Determines age based on the date of birth and a specified current date.
* Outputs the calculated age in years, months, and days.

<hr/>

Technologies Used:

1. HTML: Structure of the calculators and input fields.
2. CSS: Styling, transitions, and visual effects for dynamic outputs.
3. JavaScript: Logic for calculations, validations, and DOM manipulations.

<hr/>

How to Use:
* Open the application in any modern web browser.
* Navigate to the desired calculator section.
* Enter the required inputs in the respective fields.
* Click the Check or Calculate button to view the result.
* Use the Reset button to clear inputs and outputs.

File Dependencies:

* Images: Emojis used in results are located in the Find-Anything-Images/ directory.
  Example: 11.png for Underweight, 12.png for Normal, etc.
